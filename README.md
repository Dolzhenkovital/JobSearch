# JobSearch

Приватний помічник для пошуку роботи в Канаді: збір вакансій, оцінка відповідності досвіду, адаптація CV та lettre de motivation, облік заявок.

**Поточний стан:** підготовлено п'ять скілів для розробки й використання сервісу. Застосунок, підключення до акаунтів і регулярний збір вакансій ще не реалізовані.

## Скіли

| Скіл | Коли використовувати |
| --- | --- |
| [jobsearch-build](.agents/skills/jobsearch-build/SKILL.md) | Планування й реалізація функцій, облік заявок, перевірка результату. |
| [jobsearch-sources](.agents/skills/jobsearch-sources/SKILL.md) | Джерела вакансій, API/MCP/RSS, поштові сповіщення, повні описи, дублікати й актуальність. |
| [jobsearch-profile](.agents/skills/jobsearch-profile/SKILL.md) | Підтверджений профіль досвіду з CV та уточнень, історія змін і побажання до роботи. |
| [jobsearch-match](.agents/skills/jobsearch-match/SKILL.md) | Відповідність вимогам вакансії, переносні навички, прогалини й обґрунтований відбір. |
| [jobsearch-documents](.agents/skills/jobsearch-documents/SKILL.md) | Адаптовані CV/lettre, DOCX/PDF, пояснення змін і візуальна перевірка. |

Скіли зберігаються у `.agents/skills/` і доступні Codex у контексті цього репозиторію. Вони містять інструкції, довідки й порожні шаблони; самі по собі не надають доступ до платформ і не запускають оновлення.

Для роботи відкрийте локальний каталог JobSearch як проєкт у Codex. Скіли можуть обиратися автоматично за завданням або викликатися явно:

```text
Використай $jobsearch-build і реалізуй перший наскрізний сценарій:
ручне додавання вакансії, приватний профіль і пояснення відповідності.
```

```text
Використай $jobsearch-sources: перевір Job Bank для заданих
міста й типів посад та реалізуй отримання нових вакансій.
```

```text
Використай $jobsearch-profile для наданого CV.
Збережи профіль у private/ і покажи лише суттєві питання до фактів.
```

```text
Використай $jobsearch-match для мого профілю та цих вакансій.
Поясни відповідність і окремо познач невідомі дані.
```

```text
Використай $jobsearch-documents для обраної вакансії.
Підготуй CV та lettre de motivation, поясни зміни й перевір верстку.
```

## Зафіксовані рішення

- Початкова аудиторія — одна кандидатка; функції публічного сервісу не входять до першого етапу.
- Володіння мовами не впливає на фільтрацію, рейтинг чи відхилення вакансій. Мова документа задається окремо.
- Місто, цільові посади, графік, дорога й зарплата залишаються налаштуваннями. Невідомі значення не вигадуються.
- Короткого опису з email/RSS достатньо для попереднього відбору. Для готового пакета документів потрібен повний зміст вакансії.
- Відомості у CV мають спиратися на вихідні документи або підтвердження користувача.
- Генерація документів, їх схвалення та подання заявки — різні стани.

## Особисті дані

Код і скіли розміщені у публічному репозиторії. Реальні CV, профілі, поштові листи, токени, кеші вакансій і готові заявки зберігайте в `private/`, `data/`, `outputs/` або окремому приватному сховищі. Ці каталоги виключено з Git. Порожні шаблони й синтетичні приклади можна зберігати в репозиторії.

Наступний крок — погодити один невеликий сценарій першої версії та реалізувати його на реальному, дозволеному джерелі даних.
